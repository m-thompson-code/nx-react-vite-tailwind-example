# Hello World

serving

```
npm run dev -w apps/first-app
npm run dev -w apps/second-app
```

building

```
npm run build -w apps/first-app
npm run build -w apps/second-app
npm run build -w libs/shared
```

preview

```
npm run preview -w apps/first-app
npm run preview -w apps/second-app
```

unit tests

```
npm run test -w apps/first-app
npm run test -w apps/second-app
```

e2e

```
npm run e2e -w apps/first-app-e2e
npm run e2e -w apps/second-app-e2e
```
